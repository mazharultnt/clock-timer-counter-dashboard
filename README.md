# Clock, Timer and Counter Dashboard

A small dashboard I made to practise JavaScript timers, state and events. No frameworks, no build step.

## What it has

- **Clock**: shows the live time and date, with a 12-hour or 24-hour switch (the choice is remembered)
- **Timer**: a countdown with Start, Pause and Reset
- **Counters**: add your own counters, then use plus, minus, reset or remove (they are saved in the browser)

## What I practised

- `setInterval` and `clearInterval`
- Keeping values in variables and updating the page from them
- Creating elements with `document.createElement`
- One click listener for many buttons (event delegation)
- `localStorage` for saving data

## How to run

Open `index.html` in a browser, or use Live Server in VS Code.

## Files

- `js/clock.js`, `js/timer.js`, `js/counters.js` - one file for each part
- `css/style.css` - all the styles

Built with HTML5, CSS3 and vanilla JavaScript.
